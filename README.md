# Zaf Hossain — Portfolio (Starter)

This is a simple multi-page portfolio starter (vanilla HTML/CSS/JS).

## Quick start (VS Code)
1. Download and unzip.
2. Open the folder in VS Code.
3. Run with a local server:
   - **Option A (recommended):** Install the VS Code extension **Live Server** → right click `index.html` → **Open with Live Server**
   - **Option B:** `python -m http.server 8000` then visit `http://localhost:8000`

## Swap in your logo
Replace: `assets/logo.svg` with your own logo.
- Keep the same filename for zero code changes, OR update the `<img src="...">` in the HTML files.

## Edit content
- `about.html`
- `projects.html`
- `publications.html`
- `contact.html`

## Behavior requested
- On load, you see a centered logo.
- After ~3 seconds, a vertical menu fades in on the left (mobile: bottom).
- Hover styles included; clicking navigates to the page.
